## 🚀 Quick Start

### For Users
1. Open Telegram
2. Search: **@AtelierTelegramFaqBot**
3. Send `/start`
4. Tap a button or ask a question

### For Developers
```bash
# Clone the repo
git clone https://github.com/Maliot100X/atelier-faq-bot.git
cd atelier-faq-bot

# Install dependencies
pip install requests

# Set your bot token
export TG_TOKEN="your-telegram-bot-token"

# Run
python3 bot.py
```
